## No warranty, and specifically no authorship claim

The capitals are below, as usual. This part is in plain words because it is the
part people actually need.

This Software cannot tell you that a publication is a given researcher's work.
Author names are not unique identifiers. Where a researcher has an ORCID iD and
has claimed a work on it, this Software can follow that claim, and the claim is
theirs rather than this Software's. Everywhere else it is matching names,
affiliations and topics, and a match is an estimate.

Where this Software reports a confidence score, that score is a probability and
not a guarantee. A list it produced at a ninety percent threshold is expected to
contain wrong entries. Publication lists on a public profile are read as
statements of fact about a person's record, so a human being decides what
appears on one. This Software prepares that decision; it does not make it.

Some sources cannot run in some installations, because the credential is absent
or the identifier was never recorded. Where that is true the Software reports it.
Read what it says ran, not only what it found: an empty list from a source that
never ran means nothing at all.
